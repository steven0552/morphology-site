## 1. 3 分鐘快速上手

1. 打開網站，頁首選擇市場：**加密貨幣**或**台股**。
2. 在「**型態清單**」中，用 **週期**（4 小時／日線／週線）、**狀態**、**類型** 縮小範圍，或在「搜尋幣種」輸入代號（例如 `BTC`、`2330`）。
3. 點任何一列，會展開**K 線圖**，圖上已標好頸線、突破點、TP1／TP2 與失效價。
4. 覺得值得追蹤的，按 ★ 加入**觀察名單**。
5. 想回到全部清單，用左上角 ☰ 選單切換。

> 不登入也能使用全部功能。

## 2. 什麼是頭肩底？

頭肩底（Inverse Head and Shoulders）是一種**可能反轉向上**的價格型態，由五個點組成：

| 點 | 名稱 | 意思 |
|---|---|---|
| **LS** | 左肩 | 第一個低點 |
| **N1** | 頸線點 1 | 左肩之後的反彈高點 |
| **H** | 頭 | 整段**最低**的低點 |
| **N2** | 頸線點 2 | 頭之後的反彈高點 |
| **RS** | 右肩 | 再次回落的低點，高度和左肩接近 |

把 **N1 與 N2 連成一條線，就是「頸線」**。價格由下往上**突破頸線**，傳統上被視為可能轉強的訊號。

```
            N1 ╲            ╱ N2
           ╱    ╲          ╱    ╲
        LS        ╲      ╱        RS  ↗ 突破頸線
                     ╲  ╱
                       H（最低）
```

## 3. 四種狀態怎麼看

| 狀態 | 白話說明 | 你可以怎麼用 |
|---|---|---|
| 🟡 **右肩形成中** | 右肩還沒定型，圖上的 RS 是**暫定點**（虛線），會隨新 K 線移動 | 最早期的觀察階段，變動最大 |
| 🔵 **右肩已確認** | 右肩定型了，價格**還沒突破**頸線 | 可放進觀察名單，等待突破 |
| 🟢 **已突破** | 價格（含影線）已穿過頸線，並超過一點緩衝 | 剛突破的訊號最新鮮 |
| ⚪ **已過期** | 太久沒動靜，或突破已經很久 | 參考價值較低，預設不列出 |

> 💡 「右肩已確認」和「觀察名單」是不同的東西：前者是**型態狀態**，後者是**你自己收藏的清單**。

## 4. 分數、目標價、失效價

### 分數（滿分 100）
分數越高，代表型態越「標準」：

| 項目 | 滿分 | 看什麼 |
|---|---|---|
| 左右肩對稱 | 30 | 兩個肩膀的跌幅是否接近 |
| 頭部深度 | 25 | 頭是否明顯比肩膀深 |
| 頸線平緩 | 25 | 頸線是否平緩（太陡扣分） |
| 突破／接近頸線 | 20 | 已突破得滿分，離頸線越近分越高 |

> 右肩還在形成時，價格通常離頸線很遠，所以分數普遍偏低，這是正常的。

### 價位標示

| 標示 | 意思 |
|---|---|
| **TP1** | 第一個目標價：以頭部低點為 0、頸線中點為 1，取 1.414 倍的位置 |
| **TP2** | 第二個目標價：突破價 ×（1＋頭到頸線的漲幅）。尚未突破時用目前頸線價估算，**屬預估值** |
| **失效價** | 頭部的最低點。價格跌破，代表這個型態已被破壞 |

> 所有計算只用「已收盤」的 K 線，不會事後偷改（除了暫定的右肩）。

### 形狀驗證
每個型態還要通過額外檢查才會被列出，例如：五點之間沒有夾著更大的轉折、走勢貼合五點骨架、頸線被突破前沒有收盤站上頸線。詳細數值在每個型態的詳細頁「**形狀驗證**」區。

## 6. 讀懂圖表

- **紅／綠線**：頸線（延伸到最新一根 K 線）。
- **虛線**：右肩暫定、或延伸出去的線。
- **標記點**：LS、N1、H、N2、RS 與突破點。
- **水平線**：TP1、TP2、失效價。
- **下方柱狀圖**：成交量（綠＝漲、紅＝跌）。

**操作小技巧：**
- 在**右側價格軸**滾動滾輪，或上下拖曳，可以拉長或壓扁 K 線。
- 按鍵盤 **`A`** 或在價格軸**雙擊**，恢復自動縮放。

## 7. 收斂三角

從 ☰ 選單進入「**收斂三角**」。三角形由兩條趨勢線組成：

- 🔴 **阻力線**：連接波段高點
- 🟢 **支撐線**：連接波段低點

兩條線往右收斂，交會在「頂點」（圖上虛線）。

| 類型 | 阻力線 | 支撐線 | 傳統傾向 |
|---|---|---|---|
| 上升三角 | 水平 | 上升 | 偏多 |
| 下降三角 | 下降 | 水平 | 偏空 |
| 對稱三角 | 下降 | 上升 | 中性 |

- **收斂中**：還沒突破。
- **向上突破／向下突破**：收盤價超出阻力線／跌破支撐線（含一點緩衝）。
- **目標價**：把三角形高度，從突破價往突破方向量出去。

> ⚠️ 「偏多／偏空」只是標籤。統計上下降三角也常向上突破，**請以實際突破方向為準**。
> 目前收斂三角**沒有**觀察名單星號與 Discord 通知。

## 8. 觀察名單（星號）

- 按 ★ 就能把型態加入觀察名單；再按一次取消。
- 兩個市場（加密貨幣、台股）**共用一份名單**，每筆會標示市場。
- 名單**只存在你這個瀏覽器**（localStorage），不會上傳。
- **換裝置或清除瀏覽資料前，請先到「設定」→「匯出」備份**，新裝置再用「匯入」貼上即可。
- 瀏覽器停用儲存時，網站仍可使用，只是不會記住你的星號。

### 用 Discord 登入（選用）
登入後，觀察名單會同步到 Discord 機器人；當你關注的型態**狀態改變**（例如右肩已確認 → 已突破）時，機器人會通知你。通知方式（私訊或頻道）可在「設定」調整。

> 此功能需要站長自行設定 Discord 機器人。沒有設定時，登入按鈕會顯示「暫時無法使用」，不影響其他功能。

## 11. 常見問題

**Q：看到「已突破」，現在追進去可以嗎？**
A：本工具只告訴你「型態成立了」，不是買賣建議。請搭配自己的資金管理與風險評估。

**Q：為什麼某個型態昨天有，今天不見了？**
A：可能已過期、型態被破壞（跌破失效價），或右肩暫定點隨新 K 線移動後不再符合條件。

**Q：為什麼「右肩形成中」的分數都很低？**
A：右肩形成時價格通常離頸線還很遠，「接近頸線」那一項得分少。

**Q：TP1、TP2 一定會到嗎？**
A：不一定。它們是依幾何規則推算的**參考目標**，不是預測保證。

**Q：圖表會重畫（repaint）嗎？**
A：只用已收盤 K 線計算，結果不會事後改寫；唯一例外是「右肩形成中」的暫定右肩。

**Q：清單是空的或一直顯示「正在讀取掃描資料…」？**
A：網站的資料是由掃描程式定期產生的。如果站長沒有持續更新資料，頁面會顯示舊資料或讀不到資料。

**Q：我的觀察名單不見了？**
A：名單存在瀏覽器裡，換瀏覽器、換裝置或清除資料就會消失。請定期用「匯出」備份。

## 13. 給站長：部署與維護

這個資料夾是**純靜態網站**（`index.html`＋`css/`＋`js/`＋`img/`＋`data/`），不需要建置。

```
├── index.html
├── css/  js/  img/
├── data/        ← 掃描結果（scan.json、bars/、triangles.json、tw/ …）
├── _headers     ← Cloudflare 標頭與快取
└── wrangler.toml
```

**本機預覽**
```bash
python -m http.server 8000     # 開啟 http://localhost:8000
```

**上傳 GitHub**（檔案很多，請用指令或 GitHub Desktop，不要用網頁拖曳）
```bash
git init -b main && git add . && git commit -m "init"
git remote add origin https://github.com/你的帳號/head-shoulders-site.git
git push -u origin main
```

**部署 Cloudflare Pages**
Workers & Pages → Create → Pages → Connect to Git → 選此 repo：
Framework preset 選 `None`，Build command 與 Build output directory 都留空。

**讓資料持續更新：**`data/` 是掃描程式產生的。要自動更新，需另外執行掃描專案（Python＋GitHub Actions），並把結果推送到這個 repo；否則網站只會顯示目前這份快照。

**Discord 登入（選用）：**`js/app.js` 約第 1701 行的 `YOUR_SUBDOMAIN` 是 Discord 觀察名單 Worker 的網址佔位，沒有自己的 Worker 請保持原樣。
